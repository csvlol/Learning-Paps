# 🎵 Learning Pap's

### Your Music. Your Library. Your Experience.

Learning Pap's is a lightweight Windows desktop music player
built for music discovery, playlists, and personalized listening.

## ✨ Features
- Music search and discovery
- Personal music library
- Custom playlists
- Smart playback queue
- Shuffle and playback controls
- Music recommendations
- Gaming Mode
- Mini-player and fullscreen playback
- Backup and restore

## 💻 Compatibility
- Windows 10/11
- 64-bit systems
